# FileForge — 파일 자동화 도구

파일명 일괄 변경 · 폴더 정리 · PDF 병합/분할 · 문서 변환을 한 곳에서 처리하는 업무용 프로그램입니다.
**실행 전에 결과를 미리 보여주고**, 실행 후에도 **한 번에 되돌릴 수 있어** 안전합니다.

**실무자용 설명서는 [`사용자매뉴얼.md`](사용자매뉴얼.md)를 보세요.** 이 문서는 개발·배포용입니다.

| 소스 | 실행 방법 |
|---|---|
| `파일명일괄변경_윈도우용.pyw` | Python 설치 후 더블클릭 |

로컬 서버(127.0.0.1)를 띄우고 기본 브라우저에서 UI가 열립니다. 맥에서도 같은 소스가 그대로
동작합니다(`python3 파일명일괄변경_윈도우용.pyw`). `DESIGN-nike.md` 디자인 시스템 적용:
블랙/화이트/소프트그레이 팔레트, Futura 대형 헤드라인, 필(pill) 버튼, 칩 토글.

**브라우저 탭을 닫으면 서버 프로세스까지 완전히 종료됩니다.** (하트비트 감시 → 남는 프로세스 없음)

## 실행 방법 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 Python을 설치합니다.
   (설치 시 **"Add Python to PATH"** 체크 권장)
2. `파일명일괄변경_윈도우용.pyw` 파일을 **더블클릭**하면 바로 실행됩니다.

> Python 없이 쓰고 싶다면 아래 "EXE로 만들기"를 참고하세요.

## 사용 순서

1. **폴더 선택**으로 대상 폴더 지정 → 파일·폴더 목록이 미리보기 표에 나타남
2. **이름 변경 / 폴더 정리 / 폴더 만들기 / PDF·변환** 탭을 고르고 옵션을 켜면 결과가 실시간 미리보기로 표시
3. 빼고 싶은 항목은 **행을 클릭**해서 제외 (다시 클릭하면 포함)
4. **변경 실행**(`Ctrl+Enter`) 클릭 → 잘못됐으면 **실행 취소**(`Ctrl+Z`)로 원상복구

## 기능

### ✏️ 이름 변경 — 파일 + **폴더**

규칙 위의 **변경 대상** 선택칸에서 `파일만` / `폴더만` / `파일 + 폴더` 를 고릅니다.
**아래 모든 규칙이 폴더 이름에도 똑같이 적용**됩니다.

- 폴더는 확장자가 없으므로 이름 전체가 바뀝니다. `2023.연말자료` 처럼 점(.)이 들어간 폴더
  이름도 `.연말자료`를 확장자로 오인하지 않습니다.
- 미리보기에서 폴더는 앞에 📁 로 표시됩니다.
- `폴더만` 선택 시 확장자 필터는 자동으로 비활성화됩니다.
- 이름 충돌(중복 / 이미 존재)은 파일·폴더를 통틀어 검사해 자동 제외합니다.

규칙은 위에서 아래 순서로 적용됩니다.

| 규칙 | 예시 |
|---|---|
| 1. 찾기/바꾸기 | `IMG` → `출장사진` (정규식 지원) |
| 2. 자동 정리 | 연속 공백 정리, 특수문자 제거, 공백→밑줄 |
| 3. 접두사/접미사 | `보고서.xlsx` → `[영업팀] 보고서_최종.xlsx` (모든 파일에 동일 적용) |
| 파일별 텍스트 | 미리보기 표에서 **파일마다 다른 텍스트**를 앞/뒤에 입력. 칸 우하단 ■ 손잡이를 드래그하면 같은 값이 연속으로 채워지고, 엑셀에서 여러 줄을 복사해 붙여넣으면 행마다 한 줄씩 들어감 (Nike 디자인 브라우저 버전 전용) |
| 4. 날짜 붙이기 | 오늘 날짜 또는 파일 수정일, `20260613_보고서.xlsx` |
| 5. 순번 매기기 | `001_사진.jpg`, `002_사진.jpg` … |
| 6. 대소문자 | 영문 소문자/대문자/첫글자 대문자, 확장자 소문자 통일 |

### 🗂 폴더 정리

- **카테고리별**: 문서 / 엑셀·데이터 / 이미지 / 영상 / 압축 등으로 자동 분류
- **확장자별**: PDF / XLSX / JPG 폴더로 분류
- **날짜별**: 수정일 기준 `2026-06` 또는 `2026-06-13` 폴더로 분류
- **키워드별**: 입력한 키워드가 **파일명에 포함된 파일끼리** 그 키워드 폴더로 모음.
  `＋ 키워드 추가`를 클릭하면 입력칸이 1개 추가되고, **누른 채로 아래로 드래그하면 여러 칸이 한꺼번에** 생깁니다.
  (여러 키워드에 걸리면 위쪽 키워드 우선, 어디에도 안 맞는 파일은 그대로 둠)

### 📁 폴더 만들기 (상단 "폴더 만들기" 탭)

원하는 폴더를 한 번에 최대 500개까지 만듭니다. **이미 있는 폴더는 건너뛰고 절대 덮어쓰지 않습니다.**

| 방식 | 설명 | 예 |
|---|---|---|
| **목록으로 만들기** | 한 줄에 하나씩 이름 입력 (엑셀에서 복사·붙여넣기 가능). `/` 로 하위 폴더 지정 | `2026/01월` |
| **번호로 만들기** | 앞이름 + 일련번호 + 뒷이름 | `사진_001` … `사진_010` |
| **날짜로 만들기** | 시작~종료 기간을 일/주/월 단위로 | `2026년 01월` … `2026년 12월` |
| **조합으로 만들기** | A 목록 × B 목록 (중첩 `A/B` 또는 결합 `A_B`) | `영업팀/1월` |
| **파일 이름으로 만들기** | 폴더 안 파일 이름에서 폴더명 추출 (전체 / 기호 앞부분 / 앞 N글자). 체크하면 **파일도 함께 이동** | `2024_홍길동_계약서.pdf` → `2024/` |

공통 옵션
- **상위 폴더**: 지정하면 그 폴더를 먼저 만들고 그 안에 나머지를 생성
- **하위 폴더 공통 생성**: 만들어지는 모든 폴더 안에 같은 하위 폴더 생성 (예: `01_원본, 02_작업, 03_완료`)

실행 전 **트리 미리보기**로 `신규` / `이미 있음` 을 확인할 수 있고, 실행 후 **실행 취소**를 누르면
방금 만든 폴더만(그리고 함께 옮긴 파일까지) 원래대로 되돌아갑니다.

### 📄 PDF · 변환 (상단 "PDF · 변환" 탭)

폴더를 선택하면 해당 형식의 파일이 목록에 뜨고, 동그라미를 눌러 선택(또는 "폴더 안 전체 선택")합니다.

| 작업 | 설명 |
|---|---|
| **PDF 병합** | 선택한 PDF들을 하나로 합침. 파일명 **오름차순/내림차순** 선택, 특정 파일만 골라서 또는 폴더 전체. 각 파일 오른쪽 칸에 **페이지 범위**를 적으면 그 페이지만 합칩니다 (아래 참고) |
| **PDF 분할** | PDF 1개를 골라 **N페이지마다** 잘라 새 폴더(`원본_분할/`)에 저장 |
| **이미지 → PDF** | 여러 장의 JPG/PNG 스캔본을 한 PDF로 묶음 (정렬 순서 선택) |
| **PDF 용량 줄이기** | 이미지 압축으로 파일 크기 축소 → `_압축.pdf` (원본 유지). 이메일 첨부용 |
| **엑셀 → PDF** | 선택한 엑셀 파일들을 각각 PDF로 변환 (서식·차트 유지) |

#### 📑 PDF 병합 — 페이지 범위 지정 (필요할 때만)

특정 페이지만 골라서 합치고 싶을 때 사용합니다. **그냥 비워두면 파일 전체가 합쳐집니다.**

1. **PDF 병합**에서 합칠 파일들을 선택합니다.
2. 선택한 파일 행 **오른쪽 칸**에 원하는 페이지를 적습니다.
   - `1-5` → 1쪽부터 5쪽까지
   - `1-5, 7-8` → 1~5쪽 + 7~8쪽 (쉼표로 여러 범위)
   - `3` → 3쪽 한 장만
   - 비워두면 → 그 파일은 **전체** 페이지
3. **실행**하면 파일별로 적어둔 페이지만 순서대로 하나의 PDF로 합쳐집니다.

> 페이지 번호는 **1쪽부터** 셉니다. 없는 페이지(예: 10쪽짜리에 `20`)나 거꾸로 된 범위(`5-2`)를 적으면
> 어떤 파일이 잘못됐는지 알려주고 멈춥니다.

> PDF 기능은 첫 사용 시 `pypdf`·`Pillow` 라이브러리를 **자동 설치**합니다 (빌드된 맥 앱에는 내장).
> **엑셀→PDF**는 무료 **LibreOffice** 설치가 필요합니다 ([다운로드](https://www.libreoffice.org/download) ·
> 맥은 `brew install --cask libreoffice`). **용량 줄이기**는 `Ghostscript`가 있으면 더 강하게 압축합니다.

### 안전장치

- 이름이 서로 겹치거나, 같은 이름의 파일이 이미 있거나, 금지 문자(`\/:*?"<>|`)가
  들어가면 **⚠ 표시 후 자동 제외** — 실수로 덮어쓰는 일이 없습니다.
- 모든 변경·이동은 **실행 취소** 버튼으로 되돌릴 수 있습니다 (여러 번 누르면 차례로 되돌림).
- 확장자 필터(예: `jpg,png`)로 특정 파일만 골라서 작업할 수 있습니다.
- **폴더 만들기는 기존 폴더를 지우거나 덮어쓰지 않습니다** — 이미 있으면 건너뛰기만 합니다.
- 경로 탈출(`../`, 절대경로) 입력은 서버에서 차단해 선택한 폴더 밖은 건드리지 않습니다.

### 편의 기능

- **임시저장 / 이어서 하기**: 입력한 규칙·목록을 자동저장(마지막 저장 시각 표시). 다시 열면
  "이전 작업 내용이 있습니다. 이어서 하시겠습니까?"를 묻고 그대로 복원합니다.
- **최근 사용 기억**: 마지막 폴더·확장자 필터·탭·변경 대상을 기억해 다음 실행 시 그대로 복원.
- **폴더 열기**: 작업한 폴더를 탐색기(Finder)로 바로 열기.
- **최근 작업 이력**: 화면 하단에 최근 30건 (이 컴퓨터에만 저장, 파일명은 기록하지 않음).
- **단축키**: `Ctrl+Enter` 실행 · `Ctrl+Z` 실행 취소 · `Esc` 창 닫기.
- **부분 실패 허용**: 여러 건 처리 중 일부가 실패해도 나머지는 계속 진행하고 실패 목록을 요약합니다.

## EXE로 만들기 (Python 없는 PC에 배포)

**Windows PC에서** `EXE만들기.bat`을 더블클릭하면 `dist\FileForge.exe`가 생성됩니다.
이 파일 하나만 복사해서 Python 없는 PC에서도 더블클릭으로 실행할 수 있습니다.

> EXE 빌드는 Windows에서만 가능합니다 (macOS에서 Windows용 EXE 크로스 빌드 불가).
